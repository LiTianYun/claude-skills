## 一、产线三命令

### 0x71 外部看门狗测试（危险：BMU 将复位）

**请求**：`0x1871 C9 C8`，Byte0=0xA5（密钥），Byte1~7 任意

**回复**：PF=0xB6，Byte0=0xA5 回显 → 随后 BMU 关中断死循环，约 1.6s 后被外部看门狗复位

**验证方法**：收到 0xB6 → 等 8 秒 → 发 0xFD 查 UID，能收到 4 包即为复位重上线成功。

**注意**：非 0xA5 的 Byte0 会被忽略（无回复）；若外部看门狗损坏 BMU 永久挂死，只能断电。

### 0xFD 芯片 UID 查询

**请求**：`0x18FD C9 C8`，数据任意

**回复**：PF=0xFD，共 **4 包**（Byte0=包序号 1~4），每包 Byte1~4 为一个 32-bit UID word（Big-endian）：

```
包1: 01 39 0A 47 16    → word0 = 0x390A4716
包2: 02 37 32 32 30    → word1 = 0x37323230
包3: 03 60 8A 33 32    → word2 = 0x608A3332
包4: 04 4B 57 2D 54    → word3 = 0x4B572D54
完整 UID = 390A4716_37323230_608A3332_4B572D54
```

UID 来自 MCU（RA2L1）自身 Unique ID 寄存器，与 AFE 是否在线无关。读取失败时 BMU 静默不回，上位机按超时判定。

### 0x0C 强制均衡（回复 PF=0x74）

**请求数据格式**：

| 模式 | Byte0 | Byte1 | Byte2 | Byte3 | 说明 |
|------|-------|-------|-------|-------|------|
| 关闭所有 | 0x00 | 任意 | 任意 | 任意 | |
| 单通道开（位累加） | ≠0,≠0xAA | **全局通道号 1~104** | 均衡模式 | 0x00 | 多次发送叠加开启 |
| 单 AFE 全开 | ≠0,≠0xAA | **0x00** | 均衡模式 | **AFE 编号 1~8** | 其余 AFE 自动清零 |
| 全 AFE 全开 | **0xAA** | 任意 | 任意 | 任意 | 旧协议 Byte6=1 也兼容 |

全局通道号 → AFE 映射：通道 N 属于第 `⌈N/13⌉` 个 AFE（每 AFE 13 节），AFE 内通道 = N-13×(afe-1)。例：通道 40 = AFE4 通道 1。

**回复（PF=0x74）**：

| Byte0 (mode) | Byte1 | Byte2 | Byte3 | Byte4 |
|--------------|-------|-------|-------|-------|
| 0=关闭 / 1=单通道 / 2=单AFE / 3=全AFE / 0xFF=自动模式忽略 | AFE 编号 | AFE 内通道 | 当前开启通道总数 | 均衡模式（0=关，2=被动） |

**前置条件**：EnBal 必须为 0（手动模式），否则一律回 mode=0xFF。见 [0x01 帧](#二0x01-系统状态帧主机bmuv含-enbal-切换)。

**实测样例**（BMU1，AFE1/AFE4 接电池）：

```
单AFE4全开  TX 01 00 02 04 00 00 00 00 → RX 02 04 00 0D 02  (13通道)
关闭所有    TX 00 ...                 → RX 00 00 00 00 00
```

## 二、0x01 系统状态帧（主机→BMU，含 EnBal 切换）

这是 BC 主机的周期状态帧，BMU 解析多个字段：

| Byte | 含义 | 备注 |
|------|------|------|
| 0~1 | 总电流（mA 偏移编码，30000=0A） | Byte0=高字节，24000~36000 有效 |
| 2~3 | 簇平均电压 AvrVol_B | |
| 4 | DoFlag（DO 输出控制） | 0=不控制 |
| 6 | TestMode | ≠0 进工装模式 |
| 7 | **EnBal** | **0=手动均衡，1=自动均衡** |

调试常用：发 `75 30 0C E4 00 00 00 00`（电流 0A、均压 3300mV、手动均衡）——`bmu_cmd.py manual` 即此帧。

**注意**：EnBal 经此帧修改只写 RAM，不落盘，BMU 复位后恢复 Flash 中的值。持久修改需 `0x12/0xBC` 恢复出厂（EnBal 出厂默认 0，但会清空全部参数）或由 BC 周期下发。

回复：PF=0x0B（系统状态1）+ PF=0x0C（系统状态2）两帧。

## 三、0x12 复位子命令

| Byte0 | 动作 | 危险级别 |
|-------|------|----------|
| 0xBA | 立即软件复位（`__NVIC_SystemReset`） | 中 |
| 0xBC | **恢复出厂参数并复位**（清空校准值、SN、全部 Keep 参数，EnBal 归 0） | **高** |
| 0xFF | 查询编译信息（回复编译时间戳） | 无 |

0xFF 复位升级命令：仅当 SA=0xFF 时触发系统复位进入升级。

## 四、查询类命令速查表

请求数据无特殊说明时全 0 即可。回复 PF 为十进制编号（固件 `Send_CAN0_Manage` 第一参数），已换算十六进制。

| 请求 PF | 功能 | 回复 PF | 备注 |
|---------|------|---------|------|
| 0x01 | 系统状态（写电流/EnBal 等） | 0x0B, 0x0C | 见上节 |
| 0x03 | 单体温度 | 0x1F~ 连续 N 包 | 每包 4 个 2 字节值，原始值=(T+80)×10，包数随温度数变化 |
| 0x04 | 单体 SOC | 0x29~ | 多包 |
| 0x05 | 单体电压告警保护参数 | 0x33 | |
| 0x06 | 单体温度告警保护参数 | 0x3D | |
| 0x07 | 组端电压告警保护参数 | 0x47 | |
| 0x08 | 电池节数/温度个数/容量 | 0x51 | |
| 0x0B | 单体均衡状态 | 0x6F~ 连续 N 包 | 位图，每包 Byte4~7 共 4 字节，包数=ceil(总节数/32)，随平台变化 |
| 0x0C | 强制均衡 | **0x74** | 见产线命令 |
| 0x0D | 初始化 SOC | — | Byte0=0 全体 / Byte0=节号单体 |
| 0x0E | 单体 SOC 告警参数 | 0x79 | |
| 0x0F | 充放均衡电流告警参数 | 0x83 | |
| 0x10 | 均衡电流 | 0x8D | |
| 0x11 | 电池类型/分流器/电流校准 | 0x8E? | |
| 0x12 | 复位/出厂/编译信息 | — | 见上节 |
| 0x13 | 单体电压 | 0xBF~ 连续 N 包 | 每包 4 节×2 字节 mV（大端），65000=掉线，包数随节数变化 |
| 0x14 | 心跳 | 0xC9 | 实测回复 PF=0xC9，非文档标的 0xA1 |
| 0x15 | 扩展地址 | 0xAB | |
| 0x17 | 电压补偿值 | 0xB5 | |
| 0x18 | 模块序列号 | 0xB9 | |
| 0x19 | 最高最低信息 | 0xBD | |
| 0x1A | 完整版 SN 码 | 0xC1 | |
| 0x1F/0x20 | 电压校准 K1~K4 / K5~K8 | — | |
| 0x27 | 扩展配置（B9-/SOC/OW） | — | |
| 0x28 | NTC 类型（10/100） | — | |
| 0x2D | AFE 温度 | — | |
| 0x71 | 看门狗测试 | 0xB6 | 见产线命令 |
| 0x72 | 自动分配地址 | 0xF2 (0x72+0x80) | 菊花链用 |
| 0xFD | 芯片 UID | 0xFD ×4 包 | 见产线命令 |
| 0xFF | 复位升级 | — | SA 须为 0xFF |

> 未定义的 PF 会收到 PF=0xFE 回复（Byte0=原命令码）。
> 表中带 `?` 或未填的回复 PF 未逐一实测，以固件 `can0.c` 中对应 `Send_Cmd_*` 函数为准。
